# Amazon Sales Analysis

## 📊 Project Overview

This project analyzes Amazon sales data using Microsoft Excel and SQL
to identify sales trends, customer order patterns, product performance,
fulfilment performance, and promotion usage.

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- SQL
- GitHub

## 📌 Key KPIs

- Total Sales: ₹7.86 Cr
- Total Orders: 1.20 L
- Total Units Sold: 1.17 L
- Average Order Value: ₹652.88
- Cancellation Rate: 4.71%

## 📈 Excel Dashboard

The dashboard provides analysis of:

- Top 10 Cities by Orders
- Top 10 States by Orders
- Monthly Sales Trend
- Sales by Category
- Cancellation Rate
- Average Order Value
- Month and Day filters

## 🔎 SQL Analysis

The SQL analysis answers questions such as:

- What is the total revenue?
- Which products/SKUs sell the most?
- What percentage of orders are cancelled?
- How does Easy Ship compare with other fulfilment methods?
- What is the distribution of order statuses?
- Which categories have the highest average order value?
- Which products have high quantity but relatively low revenue?
- How many orders use promotions?
- What are the total sales by month and category?
- Which promotion types are most frequently used?
- Which states generate the most revenue?
